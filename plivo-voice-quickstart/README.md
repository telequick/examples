# Plivo Voice Quickstart → TeleQuick

A port of Plivo's Python voice quickstarts
([plivo-examples-python](https://github.com/plivo/plivo-examples-python) —
`voice/greet_caller.py`, `voice/text_to_speech.py`, `voice/receive_calls.py`,
`voice/forward_calls.py`). Plivo's model is an *answer URL*: their cloud calls
your Flask server, which returns XML verbs (`<Speak>`, `<Dial>`, …) that Plivo
executes. TeleQuick inverts that — your worker dials **out** to the engine and
the live call (audio and all) is handed to your Python function. No Flask, no
public URL, no ngrok.

## What maps to what

| Plivo | TeleQuick |
| --- | --- |
| answer URL returning XML | none — route the number to your external agent in the console |
| `<Speak>Hello…</Speak>` | `call.send_audio(pcm16)` — any TTS you like, or a console agent with a scripted prompt |
| `<Play>file.mp3</Play>` | `call.send_audio()` of a decoded 8 kHz WAV (this example's `greeting.wav`) |
| `<Dial><Number>…` / forward_calls.py | `voice.calls.transfer {orgId, sid, …}` management op |
| `<GetDigits>` / IVR | read `call.audio()` frames — DTMF and speech are both just audio to your code |
| `RestClient().calls.create(from, to, answer_url)` | `voice.calls.originate {to, from?, trunkId, agent?}` (`originate_call.py`) |
| machine detection / call recordings | platform recordings + `voice.recording.ready` webhook |
| caller lookup via `request.values['From']` | `call.caller_number` / `call.called_number` |

## Files

- `greet_caller.py` — worker: answers inbound calls, plays `greeting.wav`
  (or a synthesized chime if the file is absent), hangs up.
- `originate_call.py` — CLI: place an outbound call and connect it to an agent.

## Run it

1. Console → Agents → **External agent** → mint a media key/secret and a
   handle (e.g. `plivo-quickstart`), and route a number to it.
2. `cp env.example .env` and fill in the `TELEQUICK_*` values, then
   `export $(grep -v '^#' .env | xargs)` (or use your own env loader).
3. `pip install -r requirements.txt`
4. `python greet_caller.py` — then dial the number you routed.

### Bring your own greeting (`<Speak>` equivalent)

Drop **any 8 kHz mono 16-bit WAV** next to `greet_caller.py` as
`greeting.wav` — generated by whichever TTS you prefer. One-liner with
OpenAI TTS (then resample to telephony rate):

```bash
curl -s https://api.openai.com/v1/audio/speech \
  -H "Authorization: Bearer $OPENAI_API_KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o-mini-tts","voice":"alloy","input":"Hello, welcome to TeleQuick.","response_format":"wav"}' \
  -o tts24k.wav
ffmpeg -y -i tts24k.wav -ar 8000 -ac 1 -sample_fmt s16 greeting.wav
```

Without the file, `greet_caller.py` synthesizes a short two-tone chime so the
quickstart works out of the box.

### Outbound (calls.create equivalent)

```bash
export TELEQUICK_API_KEY=mpk_...   # console → Settings → API keys
export TELEQUICK_ORG=org_...
python originate_call.py --to +15552223333 --trunk trunk_main --agent plivo-quickstart
```

When the callee answers, the engine connects them to the agent — the same
worker greets them, exactly like Plivo hitting your answer URL on pickup.
